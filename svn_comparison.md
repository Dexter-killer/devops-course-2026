# Сравнение Git и SVN

1. **Почему в Git ветвление "дешёвое", а в SVN - "дорогое"?**
В Git ветка — это просто легковесный указатель на конкретный коммит (файл в 40 байт). В SVN создание ветки требует физического полного копирования директорий проекта на сервере, что занимает много времени и места на диске.

2. **Можно ли в SVN сделать коммит без интернета? Почему?**
Нет. SVN — централизованная система, и все коммиты отправляются напрямую на единый удаленный сервер. Без доступа к сети зафиксировать историю невозможно. Git — распределенная система, поэтому локальная история доступна всегда.

3. **В каких сценариях SVN до сих пор может быть предпочтительнее Git?**
В старых legacy-проектах (особенно в банках и госсекторе), при необходимости жесткого контроля доступов на уровне отдельных папок (Git дает доступ ко всему репозиторию сразу), а также в GameDev при работе с гигантскими бинарными файлами, где необходима функция эксклюзивной блокировки файлов (file locking).
